# Tugas 3 - Compose Multiplatform Basics

## My Profile App

Aplikasi sederhana yang dibuat menggunakan Kotlin Multiplatform dan Compose Multiplatform untuk menampilkan informasi profil pengguna.

## Fitur

- Foto profil
- Nama dan program studi
- Deskripsi singkat
- Informasi kontak
- Tombol Hubungi Saya
- Dapat dijalankan pada Android dan Desktop

## Reusable Composable

Aplikasi menggunakan beberapa Composable yang dapat digunakan kembali:

- `ProfileHeader()` untuk menampilkan foto, nama, dan program studi.
- `ProfileCard()` untuk menampilkan informasi kontak.
- `InfoItem()` untuk menampilkan informasi kontak.

## Komponen Compose yang Digunakan

- Column
- Row
- Box
- Card
- Text
- Button
- Image
- Modifier
